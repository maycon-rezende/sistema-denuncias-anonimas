## Regra para novas alterações

1. Fazer uma mudança pequena e localizada.
2. Validar HTML, CSS ou JavaScript afetado.
3. Executar `git diff --check`.
4. Criar um commit descritivo.
5. Enviar com `git push origin main`.
6. Conferir o status do GitHub Pages.
